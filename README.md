# 🍽️ Zomato Insight Dashboard

## 📌 Project Overview

The **Zomato Insight Dashboard** project analyzes restaurant and food-related data to identify important business trends, restaurant performance, pricing patterns, ratings, cuisine demand, and customer preferences.

The project works with **1,000+ Zomato records** and uses **Power BI** to transform raw restaurant data into an interactive business intelligence dashboard. The dashboard includes **5+ visuals and KPI cards** to monitor important restaurant and market performance metrics.

The analysis generated **10+ business findings** that can help understand popular cuisines, pricing patterns, customer preferences, restaurant performance, and market trends.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/Zomato-Insight-Dashboard.git
```

### 2. Open Power BI

Open the Power BI project file:

```text
powerbi/Zomato_Insight_Dashboard.pbix
```

### 3. Load the Dataset

If required, update the dataset location in Power Query.

Open:

```text
Home → Transform Data
```

and verify the data source.

### 4. Refresh the Data

Click:

```text
Home → Refresh
```

to load the latest available dataset.

### 5. Explore the Dashboard

Use the Power BI dashboard to analyze:

* Restaurant performance
* Pricing patterns
* Ratings
* Cuisine demand
* Customer preferences
* Market performance
